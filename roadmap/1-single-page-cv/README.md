# Single-Page CV

> _El objetivo de este proyecto es enseñarte a crear un currículum estructurado de una sola página utilizando únicamente HTML. Te centrarás en organizar tu formación académica, tus habilidades y tu trayectoria profesional de una manera limpia y semántica. El estilo se abordará en un proyecto posterior._

En este proyecto, debes crear un CV (Curriculum Vitae) de una sola página utilizando únicamente HTML.

## Requisitos clave para este proyecto:
- HTML semántico: Utiliza las etiquetas HTML adecuadas para estructurar tu CV.
- Metaetiquetas SEO: Incluye las metaetiquetas esenciales para el SEO.
- Etiquetas Open Graph (OG): Añade etiquetas OG para mejorar la difusión en redes sociales.
- Favicon: Añade un favicon a la página de tu CV.

La estructura de tu CV debe ser fácilmente comprensible y estar lista para recibir estilos en un proyecto futuro.
