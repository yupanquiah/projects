# Sitio web HTML básico

> _El objetivo de este proyecto es enseñarte a estructurar un sitio web utilizando HTML; es decir, las diferentes secciones de un sitio, tales como el encabezado, el pie de página, la navegación, el contenido principal, las barras laterales, etc. No apliques estilos al sitio web; céntrate únicamente en la estructura. El estilizado se realizará en proyectos independientes._

En este proyecto, se requiere crear un sitio web sencillo, compuesto únicamente por HTML, con múltiples páginas. El sitio web debe contar con las siguientes páginas:

- Homepage
- Projects
- Articles
- Contact

El sitio web debe contar con una barra de navegación que esté presente en todas las páginas y enlace a todas ellas.

No es obligatorio aplicar estilos al sitio web; solo se requiere crear la estructura del sitio utilizando HTML. Los objetivos de este proyecto son:
- Aprende a crear múltiples páginas en un sitio web.
- Estructura un sitio web semánticamente utilizando HTML.
- Estructúralo de tal manera que puedas añadir estilos fácilmente más adelante.
- Añade metaetiquetas SEO al sitio web.
